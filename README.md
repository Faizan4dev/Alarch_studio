
Alarch Studio
A fully responsive Architecture & Interior Design website built with React and Tailwind CSS.
This project was developed from a Figma design and focuses on delivering a clean, modern, and premium user experience across all screen sizes.

🌐 Live Website : www.alarch.studio

✨ Features

* Fully responsive design
* Smooth UI interactions & transitions
* Dynamic project gallery with image popups
* ArchViz video integration
* FAQ accordion section
* Testimonial slider
* Calendly consultation booking
* Clean Figma-to-code implementation
🛠️ Tech Stack

* React.js
* Tailwind CSS
* JavaScript
* React Router
* Calendly Integration
